| パス | 説明 |

## ✅ 実装済み機能

### コア機能
- **3路線**: さくら線(普通/100km/h), あおば急行(快速/130km/h), のぞみ超特急(新幹線/300km/h)
- **物理エンジン**: マスコン5段＋ブレーキ9段＋非常、空気抵抗、勾配、カーブ制限
- **疑似3Dレンダリング**: 線路、沿線オブジェクト(木/建物/架線柱)、駅ホーム(屋根/柱/照明/停止マーク)、信号
- **天候システム**: 晴れ/曇り/雨/大雨/霧/雪 (視界・制動力・パーティクル)
- **時間帯**: 朝/昼/夕方/夜 (空の色/環境光/ヘッドライト)
- **スピードメーター**: 300km/h対応アナログメーター
- **モバイルタッチ操作**: 加速/制動/ニュートラル/警笛/ドア/非常ブレーキ
- **チュートリアル画面**: キーバインド一覧と高得点のコツ

### 停車・評価システム (v2)
- **±10m停車許容**: PERFECT(±1m/S), GREAT(±3m/A), GOOD(±5m/B), OK(±8m/C), FAIR(±10m/D), MISS
- **車掌フルスクリーン評価**: 各停で車掌キャラが大画面登場、ランク別セリフ、停車誤差・時刻精度・獲得ポイント表示
- **クレームシステム**: 3人転倒→注意, 5人→クレーム(-300pt), 8人→重大クレーム(-300pt) + トースト通知

### 車内カメラ (v2)
- **420×240px大画面**: レスポンシブ対応(768px以下320×180, 480px以下240×140)
- **14人の乗客**: 立ち客8人、座り客6人、バネダンパー物理モデル
- **転倒システム**: 急ブレーキ(減速度>12)・急発進(加速度>8)で転倒→×目＋グルグルエフェクト
- **乗り心地スコアバー**: リアルタイム表示、転倒/急操作でペナルティ

## 📁 ファイル構成

```
index.html          メインHTML (UI/CSS)
js/
  audio.js          Web Audio API サウンドエンジン
  config.js         ゲーム設定 (路線/天候/スコア/車掌セリフ)
  physics.js        物理エンジン (マスコン/ブレーキ/抵抗/勾配)
  renderer.js       疑似3Dレンダラー (線路/景色/駅/信号/天候)
  passenger.js      乗客シミュレーション (転倒/リアクション/乗り心地)
  events.js         全ギミック統合イベントシステム (A1-D3全13種)
  game.js           ゲームロジック (状態管理/停車評価/クレーム/イベント統合)
  main.js           UI制御・ゲームループ・結果表示
```

## 🗄️ データモデル

### rankings テーブル
| フィールド | 型 | 説明 |
|-----------|------|------|
| id | text | UUID |
| player_name | text | プレイヤー名 |
| score | number | 合計スコア |
| rank | text | S/A/B/C/D |
| station_results | text | JSON: 駅別結果 |
| replay_data | text | JSON: リプレイデータ |
| comfort_score | number | 乗り心地スコア |
| fallen_count | number | 転倒回数 |
| claim_count | number | クレーム件数 |
| event_bonus | number | イベントボーナス合計 |
| achievements | text | JSON: 解除済み実績名 |

## 🎮 操作方法

| キー | 操作 |
|------|------|
| ↑ / W | マスコン上げ (P1→P5) |
| ↓ / S | ブレーキ上げ (B1→B8→非常) |
| ← / A | 1段戻す |
| → / D | 1段進める |
| N | ニュートラル |
| Space | 警笛 (猫退避にも使用) |
| Enter | ドア開閉 |
| E | 非常ブレーキ |
